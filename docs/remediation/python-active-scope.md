## Scope risks

The source worktree contains extensive uncommitted changes, so a later scope refresh must record a new evidence timestamp. Frontend API modules can contain dead calls not represented in the Router. Workspace fields on historical resources and pre-profile embeddings are nullable/legacy and require authorized reconciliation before durable Python traffic. PostgreSQL, ingress, canary, provider quality, multi-replica lease and rollback interoperability remain unverified.
